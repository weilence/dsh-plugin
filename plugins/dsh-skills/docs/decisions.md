# 已确认决策（@weilence/dsh-skills）

本文件承载已确认的行为决策与取舍理由（为什么是这个行为）；行为表现见 [spec.md](spec.md)。

- 读侧以直接扫描为主数据源、全局注册表仅作只读补充：官方 web/desktop 组合刻意禁用 host 级 skill-filesystem（本地发现归各 agent preset 的 scoped 层），全局 `ctx.skills` 注册表默认为空——故 `ctx.get('skills')` 只可选访问、不可用时降级。
- 管理范围固定两档（用户级 / 当前工作区 + 用户级），不提供任意目录选择：范围限定为官方可发现技能根的固定组合，工作区档跟随主视图会话 cwd。
- 名称锁定不可编辑（与文件名一致）：改名或单文件 ↔ 目录包互转一律删除后新建；更深的嵌套路径不是官方可发现的技能实体，故拒绝删除。
- frontmatter round-trip 保持行级替换性质：未知字段 / 注释 / 空行原样保留在原位；新增可编辑键时延续该性质，维持无 YAML 依赖。
- 无效条目不设特殊修复路径：走与正常条目相同的编辑流程，填好 name / description 保存后即成为有效条目。
- store 一次性操作通知与组合错误在事件时间用当前语言定格（5 秒 Toast、下次操作即替换）：该反馈不需跨语言存活，属[根 docs/i18n.md](../../../docs/i18n.md)「多语言约定」节允许事件时间取词的即显一次性反馈。
