# 陷阱（@weilence/dsh-skills）

本文件承载实证事实、易错点与防错提醒；行为规格见 [spec.md](spec.md)。

- 会话目录重发只看 `name` / `description` 变化，且 watcher 有约 200ms 稳定窗口：改正文不重发目录——需要目录刷新的改动必须落在 name / description 上，别指望改正文能让运行中的会话更新目录（正文经模型下次调用 `skill` 工具读到新值，见 spec「写入生效时机」）。
- 面板每次列表请求都是实时扫描、无缓存：不要给面板加扫描缓存，也不要假设列表数据是过期快照。
- 无效条目（缺描述、名称不合法、含旧版调用策略键）不是死档：走与正常条目相同的编辑流程即可修复——不要为无效条目另写特殊处理，也不要禁止编辑。
- 新增可编辑 frontmatter 键时必须保持行级替换性质：只能扩展「已知键行」的行级替换，不得改成整块重建 frontmatter，否则未知字段 / 注释 / 空行会从原位丢失。
- 写文件用 node:fs 直接落盘：host half 是宿主侧受信代码，直接用 node 能力（理由见[根 docs/architecture.md](../../../docs/architecture.md)「双 half 架构」节）——不要绕道其他写入封装。
- `src/roots.ts` 归属判定依赖字面 + realpath 双变体（容忍 home 重定向 / 符号链接 / 大小写差异）：改动根匹配逻辑时两个变体都要顾及，只留一种会丢掉对重定向 / 链接 / 大小写差异的容忍。
- `src/frontmatter.ts` 无 YAML 依赖是既定形态（读兼容引号 / 块标量、写按 YAML 双引号标量序列化均为行级实现）：不要引入 YAML 库替代 round-trip。
