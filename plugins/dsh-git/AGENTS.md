# dsh-git

- 仓库判定三类：目录含 `.git` 目录（standard）、含 `.git` 文件（linked，按 `gitdir:` 指针解析，相对 / 绝对路径均可）、目录直接含 HEAD + objects + refs（bare）。分支解析 `HEAD`（`ref: refs/heads/` 前缀剥离；detached 40 位十六进制给短提交号），远端解析 `config` 的 `[remote "origin"]` url——**扫描发现链路全部读文件，不 spawn git**。`relPath` 是 wire / 展示字段，统一 `/` 分隔：`path.relative` 结果 `split(sep).join('/')`（Windows 产出 `\` 须规范化；不可替换字面反斜杠——POSIX 上它是合法文件名字符）。
- 扫描语义（用户已确认）：发现仓库后**继续下探**工作树（能发现嵌套仓库与子模块），但不进入 `.git` 内部、剪枝目录（`node_modules` 等，见 `scan.ts` 的 `PRUNED_DIRS`）与裸仓库内部；符号链接目录不跟随（dirent 判定天然如此）。深度 / 目录 / 仓库三上限超限置 `truncated`；深度之外未访问不算截断。
- 提交图链路（`src/log.ts`，用户已确认）：host spawn git——仓库先例 dsh-mcp。只读命令 `git log --topo-order --all` 与 `git for-each-ref`；execFile 无 shell、args 数组直传、10s 超时、`GIT_OPTIONAL_LOCKS=0`；字段分隔 `\x1f`、记录分隔 `\x1e`（subject 与多行正文 `%b` 都不会与之冲突，正文是末位字段）。refs 分类走 for-each-ref 的命名空间前缀（`REF_NAMESPACES`：branch→heads / remote→remotes / tag→tags），不解析 `%D`——本地分支可含 `/`，装饰串无法与远端区分。空仓库（stderr `does not have any commits yet`）是空列表不是错误；git 缺失（ENOENT）给明确中文错误。limit 默认 500、上限 1000，取 limit+1 条探测截断。
- 文件变更链路（`src/log.ts` 的 `readCommitFiles`，路由 `POST /plugins/dsh-git/files`，hash 校验 4–40 位十六进制）：`git show --numstat -z` 给行数、`git show --raw -z` 给状态字母，按新路径合并。`-z` 下路径无引号无花括号压缩；重命名记录两个字段 **old 在前 new 在后**（实证），numstat 重命名的路径字段为空、后跟 old/new 两个 NUL 字段；二进制行数是 `-`（置 undefined）。状态折并：T→modified、C→renamed。`--first-parent` 让合并提交展示相对第一父提交的变更（即合入内容），对普通提交无影响。client 侧展开时按需拉取并缓存（`requested` ref 防缓存写入重触发；失败不驻留缓存，重开即重试；切换仓库清空）。
- 泳道布局（`src/client/graph.ts` 纯函数）：拓扑序（子先于父）输入，每泳道记「期待的下一个提交」；命中归 lane、多命中合并、首父直行或并入既有 lane、次父开新 lane；输出每行 `incoming`（行顶入点）/`outgoing`（行底出边）/`through`（穿越竖线），渲染端每行一段 SVG strip（`CommitGraph.tsx`），无需全局协调。strip 高度必须跟随**内容列**实测高度（取 max(常规行高)，展开详情等把行撑高时穿越线与出边的竖直延伸段到达行底，否则与相邻行断线）；**出边曲线固定在常规行高内完成转向、展开区只延伸竖直直线，不得把曲线拉伸到整个展开高度**（用户已确认，参照 JetBrains 展开形态）；禁止改为观察行本身——strip 高度会反过来撑住行高，收起时行尺寸不变、高度回不去。展开/收起与文件清单异步到达的高度更新必须在 `useLayoutEffect([expanded, filesView?.phase])` 里同步测量落屏——`ResizeObserver` 回调的 setState 走并发调度、晚于当帧绘制，会闪一帧旧高度；RO 只兜底文本换行类被动变化。提交点恒锚在常规行高中点。
- host 路由（`src/index.ts`）：`POST /plugins/dsh-git/repos` 与 `POST /plugins/dsh-git/log`，guard 模式与 dsh-sessions 相同（`requestRejection` + `isTrustedFetch` + `x-dsh-git: 1`）；目录参数先 `stat` 预检，limit 非法直接 400。host 与 client 的路由常量和 wire 类型集中在 `src/shared.ts`。
- client 两段式注册（`src/client.tsx`）：标签类型进 `ctx.sidebarRightTabs.register`（`extension` 优先带缺省，指南入口 order 40 排在官方 files / terminal / browser 之后）；标签体进 keyed 槽位 `sidebar.right.pane.tab`（key = 类型 id `@weilence/dsh-git`）。扫描根取 `PropsRuntime` 标准份额 `sessionId` 对应的 `SessionSummary.cwd`；无 cwd 显示原因、不发请求；扫描与读提交各自以序号防串台。
- ReposBody 注入 `formatTime` 与 `formatRelative`（均事件时间取词，跟随宿主语言；后者用 `Intl.RelativeTimeFormat`）；仓库选择默认「会话目录所在仓库 → 首个仓库」，重扫后选中仓库消失则回落，未消失不换。头部控件：仓库下拉（底色 `bg-layer-3` 与面板区分）、「显示作者 / 时间」勾选（默认不勾）、刷新按钮。
- 提交行的信息分区（用户已确认）：收起行默认**只显示主题**（弹性截断）；头部勾选项「显示作者 / 时间」（`options.authorTime`，默认不勾选）控制行内是否追加作者（40% 宽截断）与时间。展开详情只渲染 refs 芯片（无 refs 不渲染）与文件变更清单（状态字母 / 路径 / 增删行数，超长内部滚动）——提交号、作者邮箱与变更计数**只在悬停卡片**，不在详情。行内文本不可选（`.commit` 上 `user-select: none`，用户已确认放弃划选复制），交互只保留点击与悬停：onClick 先以 `event.target.closest('[data-detail]')` 判分区，详情区点击不参与切换；紧凑行（`li` 上 `role="button"` + Enter / Space 键盘切换，行高 `ROW_HEIGHT = 28`）点击即切换、无划选仲裁（不得重新引入选区判定或按下/松开位移判定）。行底色（用户已确认）：用官方交互色——悬停 `--dsw-alias-interactive-bg-hover`，展开行 `--dsw-alias-interactive-bg-active`（比悬停深一档，规则须排在 `:hover` 之后）；浅色主题 `bg-layer-1/2/3` 同值，不可用作行底色；展开详情区盖回 `--dsw-alias-bg-base` 不参与底色变化。
- 悬停提交卡片（用户已确认，对照 GitHub hovercard）：紧凑行与展开行悬停弹出（延时默认 500ms，0–5000ms 可编辑；入口在**插件详情页**——设置 → 插件 → 点开「Git 仓库」卡片后的页面，`plugins.bundle.config` 槽位 keyed 包名，`ConfigSection` 面板整体无头部；值存 `client/hoverDelay.ts` 模块级 store——localStorage `dsh-git.hoverDelayMs` 持久化、读写 try/catch 容忍存储不可用，`useSyncExternalStore` 让配置面板与提交图面板（可同时挂载）实时一致，保存即时生效；头部不再有延时输入）；**配置面板布局对齐官方插件配置页**（用户已确认）：字段整体用官方 `SettingsValueField` 原语（字段标题 → 通宽输入框 → 辅助说明 / 错误单槽互斥、非法时输入框 `aria-invalid` 红边），草稿与默认值（500）不同时标题行右侧出现「已覆盖」徽标 + 「恢复默认」入口（官方同款，词典对齐官方译法）；「恢复默认」只把默认值暂存进草稿，写入仍由保存完成（官方口径：控件不落库，保存是唯一写入点）；草稿未变更或非法（越界 / 非整数）时保存禁用，保存把数值写入 store（越界不落库），保存按钮样式对齐官方 SettingsForm 页脚实心反色；**卡片紧贴行缘显示在行之外**（用户已确认，替代早先的指针斜向偏移）：纵向贴行缘——默认顶缘贴行底，下方放不下翻到行上方（底缘贴行顶），上下都放不下贴视口收拢；横向对齐指针 x——右侧放得下卡片左缘对齐指针（右下 / 右上），放不下右缘对齐（左下 / 左上），两侧都放不下贴视口左缘收拢；行 `onMouseMove` 持续跟踪指针 x 与行缘，弹出前移动即更新锚点。`position: fixed`；渲染后 layout effect 量实测尺寸，经 `placeCard` 纯函数（`graph.ts`，含单测）定位，绘制前完成无闪动（卡片 CSS `max-width / max-height: 视口 − 16px`，超限内部滚动）；fixed 可浮出侧栏的只是**视觉**一半（宿主契约：无 transform 祖先时 `overflow` 不裁 fixed 子元素），**命中与层叠**的另一半要求卡片经 `createPortal` 挂 `document.body`——dock 泳道单元建立 z-10 层叠上下文（dockkit `--dsh-dockkit-dock-layer`），面板树内写多高的 z-index 都被封顶，而宿主在侧栏左缘放了隐形拖拽把手（8px 全高命中条、z-11，刻意压在右栏之上「panel hangs over the centre 时仍可抓握」）：不 portal 的卡片跨过侧栏边界即被把手截走命中、触发自身 mouseleave 整卡收起（实际发生过）。挂 body 后以自身 z-index 参与顶层层序，取 50——高于把手 11 / frame overlays 20 / 右栏全屏 40，低于 dockkit 浮动面板 60 与官方弹窗 1000+（层表见 `CommitGraph.module.css` 的 `.card` 注释）；`relatedTarget` 判向不受 portal 影响（`data-hover-card` 在卡片根上，`closest` 走真实 DOM）；无 DOM 环境（node 单测）降级原位渲染（`portalTarget` 模块常量）。**可移入交互**——`pointer-events: auto` + `user-select: text`，内容可选中复制（行内不可选，卡片可选，两者不冲突）。**离开立即隐藏**（用户已确认，无宽限定时）：行 `onMouseLeave` 与卡片 `onMouseLeave` 以 `relatedTarget` 判向——落在 `[data-hover-card]`（行上移向卡片）或落在本行 `[data-hash=…]`（卡片上移回本行）时不隐藏，其余去向（换行 / 离窗）立即 `cancelHover`（同时中止未触发的弹出）；行 `onMouseEnter` 对同一提交原样保留（不重置计时、不挪锚点）；**指针换到另一行立即收起旧卡片、清空定时重新驻留——卡片只属于一次驻留，扫过列表不触发**（用户已确认）；行与卡片 0 缝隙、行到卡片不穿越相邻行，**不得引入借道宽限、轨迹 / 几何仲裁、隐藏宽限定时等特例**（用户已确认）；点击切换、列表滚动（`onScroll`）才取消。行内主题 / 作者**不挂原生 `title`**（原生提示会与卡片重复）。内容：作者、相对时间 + 绝对时间（`formatRelative` / `formatTime` 注入，事件时间取词）、主题、提交正文（`GitCommitInfo.body`，host 以 `%b` 读取）、文件变更统计（`log.summary`，行数由缓存清单累加、二进制不计）与短提交号。文件清单拉取由「展开 ∪ 悬停」合成的
