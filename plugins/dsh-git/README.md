# @weilence/dsh-git

DSH web 插件：Git 仓库发现与提交图。在右侧栏（右上角展开按钮打开的面板）新增「Git 仓库」标签：递归发现当前会话目录下的全部 Git 仓库，并在仓库间切换浏览 GitLens 风格的图形化提交历史——当前目录本身不是 Git 仓库也能找到子目录里的仓库。

## 功能

- **右侧栏标签入口**：指南页在 Workspace files / New terminal / Browser 之后新增「Git 仓库」入口，点击打开为常驻页面标签；扫描根为当前会话的工作目录，随会话切换自动重扫。
- **仓库发现**（纯文件系统检查，不依赖 git 二进制）：
  - `.git` **目录**——标准仓库，根目录即所在目录；
  - `.git` **文件**——worktree / 子模块形态，按 `gitdir:` 指针解析真实 git 目录；
  - 目录本身直接含 `HEAD` + `objects` + `refs`——裸仓库。
  - 发现仓库后继续下探工作树（可发现嵌套仓库与子模块），但不进入 `.git` 内部与裸仓库内部；跳过 `node_modules`、`.venv`、`target`、`dist` 等依赖与构建目录；符号链接目录不跟随。默认深度上限 6、访问目录预算 20 000、仓库上限 500，超限标记截断。
- **图形化提交图**（JetBrains / GitLens 风格，需要机器上有 git CLI）：
  - 泳道图：分叉、合并、穿越泳道按 GitLens 风格着色绘制，提交点标在所属泳道；
  - refs 芯片：`HEAD → 分支`、本地分支、远端分支（如 `origin/main`）、标签（如 `v1.0.0`）；
  - 每行：主题、作者、时间（跟随宿主语言格式化）；点击行内任意位置展开详情，Enter / Space 同样可切换，展开行底色高亮区分；
  - 展开详情：完整提交号、作者邮箱（均可选中复制）与**文件变更清单**——每个文件的 git 状态记号（A 新增 / D 删除 / M 修改 / R 重命名）、路径（重命名显示 `旧 → 新`，可选中复制）与增删行数（二进制文件不显示行数），清单超长时内部滚动；
  - 数据经 `git log --topo-order --all` + `git for-each-ref` 读取，文件清单在展开时按需经 `git show --numstat --raw` 读取并缓存（合并提交按第一父提交展示合入内容）；全部只读命令、无 shell、10 秒超时，默认最近 500 个提交，超出标记截断。
- **多仓库切换**：头部下拉切换仓库，选中后自动读取该仓库提交图；显示所选仓库的根路径、当前分支与形态标记；刷新按钮同时重扫仓库与重读提交图。
- 空仓库显示空态；git 不可用、非 git 目录等失败原因行内常驻展示。

## 安装

```bash
dsh plugin --profile <name> add @weilence/dsh-git
```

（或手动把 `@weilence/dsh-git` 加入宿主 `package.json` 的 `dependencies` 与 profile 的 `dsh.profile.bundles`，启动时 profile boot 会自动合并包内的 `cordis.patch.yml`。）安装后重启宿主生效；宿主启用 HMR 时刷新页面即可。

## 使用

打开右侧栏（右上角展开按钮）→ 点击「Git 仓库」：

1. 挂载即扫描当前会话目录下的仓库，默认选中会话目录所在的仓库（否则首个仓库）；
2. 头部下拉切换仓库，下方即渲染该仓库的提交图；
3. 点击提交行任意位置展开完整提交号、作者邮箱与文件变更清单（划选文本不会触发展开）；
4. 「刷新」按钮重扫仓库并重读提交图。

当前会话尚未提供工作目录时，面板显示原因且不发起任何请求。

## 限制

- 提交图链路依赖 PATH 中的 `git`（仓库发现链路不需要）；git 缺失时面板给出明确错误。
- 提交图只读：不含分支过滤、搜索与 diff 内容查看（文件变更仅清单与行数统计）。
- 扫描深度上限之外的目录不会被访问（不算截断）；目录或仓库数量超上限才标记截断。
- 分支与远端摘要读取自 `.git/HEAD` 与 `.git/config` 的静态内容，不执行 `git status` 类动态查询。
- 剪枝目录（`node_modules` 等）内部的仓库不会被列出。
