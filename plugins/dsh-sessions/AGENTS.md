# dsh-sessions

「设置 → 会话」面板：搜索 / 过滤全部会话，归档 / 恢复、跨工作区迁移、迁移 Agent 预设、批量操作、ZIP 导入与级联删除。

理解本插件的前提：面板数据全部来自官方客户端快照、搜索过滤纯客户端实现，不读聊天内容；而删除 / 迁移 / 预设迁移绕过宿主官方接口、直接对官方 JSONL 持久化工件做磁盘手术——这是官方契约外的受控操作，宿主不感知这类改动，数据安全完全由本插件自带的闸门、互斥与回滚保证。

## 强制约定

- 活会话一律拒绝（`guards.ts` 的 `assertNotLoaded`）：绕过活内存态删除会让宿主追加路径重建部分日志。
- 一切工件改写走 `writeTempFile`（0o600 + fsync）+ 备份-发布-回滚三段式；回滚失败保留备份并上报路径。
- 损坏工件（截断帧 / 不完整尾行）与同 id 多目录一律拒绝改写，绝不猜测修补。
- 磁盘迁移发布顺序固定「先隐藏旧工件（非规范文件名对官方后端不可见）再发布新工件」，宁可短暂缺失也不产生同 id 双目录。
- 删除 / 迁移 / 预设 / 导入 / 批量路由共用同一全局存储互斥（`src/index.ts` 的 `exclusive`），新增变更路由必须接入。
- 宿主不发布会话移除事件——删除成功后客户端必须全量刷新官方会话列表（`sessions.refresh`），否则侧栏残留已删会话的隐藏过期摘要。
