# @weilence/dsh-sessions

DSH 的「设置 → 会话」页面：搜索与过滤全部会话，归档、恢复、跨工作区迁移、迁移 Agent 预设或永久删除；也支持导入宿主导出的会话 ZIP。侧栏会话行的「…」菜单提供「迁移到工作区」入口。

## 功能总览

- **会话列表**：数据来自官方会话与工作区快照，展示标题、会话 ID、工作区、工作目录、更新时间与状态徽标（已归档 / 运行中 / 子会话 / 空白）。
- **搜索**：按标题、会话 ID、工作目录路径、工作区名称或路径大小写不敏感匹配，不读取聊天内容。
- **过滤与排序**：工作区（全部 / 未分组 / 指定）、状态（全部 / 未归档 / 已归档）、显示子会话（默认隐藏）、仅运行中、显示空白会话（默认隐藏）；排序支持最近更新（默认）、最早更新、标题 A-Z / Z-A。
- **行操作**：归档 / 恢复（官方命令）、迁移到工作区（原地磁盘迁移）、迁移 Agent 预设、删除（级联子会话，需确认）。
- **批量操作**：点击「批量操作」进入批量模式，行内出现复选框与批量操作条。「选中本筛选结果」一次勾选当前搜索 / 过滤下的可见行，选择跨过滤切换保留、退出即清空。支持批量归档、恢复（客户端循环官方命令）、迁移到工作区、迁移预设与删除（先经预览弹窗确认）。单次批量上限 200 条；单项失败不中断后续，逐项明细（成功摘要 / 失败原因 / 级联数）在批量结果弹窗中分组呈现，可一键「重试失败」。
- **导入**：把宿主导出的官方 ZIP 导入为冷会话，详见下文。

## 删除会话

删除是永久操作：会话及其全部子会话后代的日志文件从存储中移除，不可恢复。宿主官方接口没有删除能力，此功能是官方契约外的受控操作。

执行顺序（任一道闸门不满足都会显式拒绝，不动任何数据）：

1. 官方持久化头现扫后代谱系（`origin === 'subagent'` 且 `parentSession` 成链）；扫描失败即拒绝。
2. 主会话与全部后代逐项预检：未加载在宿主内存、官方活动 waterfall 复查无回合 / 子代理 / 后台任务 / 定时活动、目录边界校验（两层 `<root>/<项目目录>/<会话目录>`，逐级拒绝符号链接与 junction）。
3. 后代逆序在前、主会话最后逐个删除：官方 `stat` 确认 → 写锁尽力互斥（抢到官方写锁则持锁删除；占用错误按宿主空闲句柄既有边界继续，其余错误拒绝）→ 删除目录。
4. 账本清理：清除各目标的归档条目并从工作区记录移除主会话；清理失败以警告返回，不回滚文件删除。

明确残余边界：

- 已加载在宿主内存中的会话（含主会话与后代）一律拒绝删除——绕过活内存态删除会让宿主的追加路径重建出部分日志。请重启宿主后重试。
- 与其他实例同时操作同一存储根不受保护；删除前应退出其他实例。
- 存储根目录默认按官方 home 约定解析为 `$DSH_HOME/sessions`；自定义位置请在 `sessionsRoot` 配置中显式指定。宿主未来更换存储布局时，此功能会显式失败而不是误删。

## 迁移会话到其他工作区

1. 侧栏会话行菜单或面板行内「迁移到工作区…」，弹窗内选择目标工作区并确认。
2. **快路径**：会话规范 cwd 已等于目标路径时只补挂工作区账本成员资格（官方 `attachSession`），日志原地不动——这正是「cwd 正确却停留在未分组」会话的修复入口。
3. **原地迁移**：其余情况在磁盘上原地完成——日志头的工作目录改写为目标路径并把工件发布到目标项目目录，历史事件逐字节保留；日志已有工作目录变更历史时补记一条 `working-directory/change` 事件，保证恢复后的工作目录投影正确。随后从旧工作区账本移除并挂到目标工作区。

闸门：目标工作区必须存在；子会话不提供迁移（请迁移主会话）；旧代格式日志请先在宿主中打开一次完成格式升级；会话必须未加载且无进行中的活动。

受控操作与残余边界：

- **工作区注册表头缓存在线补挂**：官方注册表把会话头缓存在私有内存 Map（启动时建立，命中即不刷新），磁盘手术后 `attachSession` 的 cwd 强校验会读到旧值。本插件按特性探测补缓存后走官方 `attachSession`；探测不到时文件已完成迁移，弹窗会提示重启宿主后再次迁移（将走快路径）完成归属。
- 迁移先隐藏旧工件再发布新工件：任何一步失败都会恢复原文件，回滚失败时把恢复文件的路径原样交给用户。崩溃窗口宁可短暂缺失也不产生同 id 双目录（官方后端会拒绝这种状态）。
- 写锁占用错误只可能是宿主空闲句柄（已由加载检查挡住活跃写入）；锁释放失败不阻断结果。
- 历史文本与工具参数中的旧绝对路径不会被改写；继续会话后须核对实际目标。
- 活会话的免重启迁移需要重绑宿主内部写入路径，官方契约不暴露，本版本不做——已加载会话一律拒绝。

## 迁移 Agent 预设

把会话最后一条 `agent-preset/selected` 事件改写为指定预设（没有选择记录时改写日志头），消息历史保持不变；用于预设被改名或删除后无法恢复的会话。目标预设必须存在于宿主预设清单；同值幂等。会话必须未在宿主中加载；宿主未挂载预设服务时功能整体禁用。

改写走备份-发布-回滚三段式原子替换；回滚失败时保留备份文件并在日志与错误信息中给出路径，请勿删除。

## 导入会话 ZIP

1. 在来源机器上等待主会话及子会话停止运行，再使用宿主自带的下载功能导出 ZIP。
2. 打开「设置 → 会话」，点击「导入」，选择目标工作区和一个或多个 ZIP；没有工作区时先在左侧列表中添加。
3. 确认 ZIP 来源可信后导入。插件逐份校验并导入；某份失败后继续处理其他 ZIP，各文件的结果和实际错误显示在底部按钮旁。
4. 成功的普通会话关联到所选工作区；完成后请求刷新会话列表。

只创建目标上不存在的会话，内容完全相同则跳过；同一 ID 的内容不同就拒绝导入，不覆盖、不合并分叉历史。目标上同 ID 的会话必须未加载到内存。写入前完成整份归档校验（CRC、附件 SHA-256、谱系、格式语义），目标发生变化时拒绝写入。

## 格式与安全边界

- 接受宿主官方 ZIP：根日志、后代会话日志及引用附件，当前只支持 V4。
- 原地迁移与预设迁移直接操作官方 JSONL 工件：保持原文件名与物理编码（纯文本或 zstd），zstd 重编码保持「头行独占第一帧」的容器契约；截断帧或不完整尾行一律拒绝改写。
- **ZIP 未脱敏、未加密**，可能包含指令、推理记录与敏感附件；点击导入表示确认来源可信，不是隔离机制。
- 单份日志由宿主持久化服务发布；整批导入不是一个全局事务，中途失败可能留下已保存会话，界面报告已完成数量，不自动回滚用户数据。
- 全部路由经宿主连接认证（拒绝跨站与非信任来源），变更路由共用存储互斥，请求体限制与导入一致。

## 限额与失败处理

| 项目         | 每份 ZIP 的上限 |
| ------------ | --------------- |
| ZIP 压缩大小 | 64 MiB          |
| 总解压大小   | 256 MiB         |
| 单个条目     | 64 MiB          |
| 单份日志     | 16 MiB          |
| ZIP 条目数   | 4096            |
| 会话数       | 256             |
| 单会话事件数 | 100,000         |

## 安装与启用

需要 DSH `0.2.1-rc.2` 的会话、附件、工作区、持久化及 Web 连接服务。zstd 工件的磁盘手术需要 Node 22.15+ / 24 的内置 zstd 支持（官方桌面版自带）。

```bash
pnpm install
pnpm --filter @weilence/dsh-sessions build
# 将路径替换为本机实际插件目录，profile 替换为正在使用的 profile。
dsh plugin --profile <profile> add /absolute/path/dsh-plugins/plugins/dsh-sessions
```

安装或更新后重启宿主，并刷新页面。宿主侧的路由变更不能仅靠刷新浏览器生效。
