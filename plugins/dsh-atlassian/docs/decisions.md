# docs/decisions.md — 已确认决策

本文件承载已确认（人拍板）的行为决策与取舍理由：改动这些行为需回到方案层，不要在代码层顺手变掉。行为表现见 [spec.md](spec.md)，防错提醒见 [traps.md](traps.md)。

- 多文档检索是定稿需求：steer 文本里「不要只看第一篇 / 末尾附清单」的措辞是产品约定，改动需回到方案层。
- 卡片侧命中条目不逐行展示（产品决策）：预览行只显示产品名与命中条数，明细看展开区的模型渲染原文。
- 卡片零固定文案：标题全部来自 meta 数据（理由：历史回放可用），失败态红点 + 错误原文；加文案的合规路径见 [traps.md](traps.md)。
- 多站点歧义 fail explicitly：未指明 `site` 且工作区与项目键都未唯一命中且无默认站点时，报错并列出可选站点名，不要改成猜第一个；`projects` 键只有唯一命中才自动选站，歧义一律回落默认站点或报错（选站顺序见 [spec.md](spec.md)「站点与凭据模型」）。
- 命令 handler 禁止网络调用：它是人类直达通道，不是模型代理（强制约定见插件 AGENTS.md）；校验输入后组织一句提示经 `agent.steer()` 提交，查询与展示全部由模型用工具完成。
- 正文转换降级不做无损往返：复杂 Confluence 宏（嵌套表格、面板宏等）与未识别的 ADF 节点回退文本提取——读取场景要的是可读正文，不是无损往返（转换行为见 [spec.md](spec.md)「结构导览」`src/markup.ts`）。
